## Purpose

Даёт установить интеграцию будильника через HACS, создать в UI произвольное число будильников (по одному на комнату) и указать для каждого набор устройств без правки YAML.

## ADDED Requirements

### Requirement: Установка через HACS
Репозиторий SHALL быть устанавливаемым в HACS как custom repository категории «Integration». Интеграция SHALL загружаться в Home Assistant версии 2025.1 и новее без сторонних Python-зависимостей.

#### Scenario: Добавление репозитория в HACS
- **WHEN** пользователь добавляет `https://github.com/seredavin/ha-alarm` в HACS как custom repository типа Integration и устанавливает его
- **THEN** после перезапуска HA интеграция «Будильник с рассветом» доступна в списке «Добавить интеграцию»

### Requirement: Создание будильника через UI
Интеграция SHALL позволять создать будильник через config flow, указав:
- имя (обязательно);
- источники света: ноль или более сущностей `light` и `switch` (лампы, розетки) в одном списке;
- колонку (Яндекс Станцию): ноль или один `media_player`;
- шторы: ноль или более `cover`.

Пользователь SHALL NOT указывать, диммируется ли источник. Интеграция SHALL определять это сама в момент срабатывания: `light` с поддержкой яркости — диммируемый, `switch` и `light` только с режимом on/off — недиммируемый. Нужно выбрать хотя бы одно устройство любого типа. Каждая запись SHALL быть независимым будильником. Имя SHALL быть уникальным среди будильников.

#### Scenario: Успешное создание
- **WHEN** пользователь вводит имя «Спальня Ульяны», выбирает источники `light.spalnia_uliany_svet` и `switch.spalnia_uliany_rozetka_uliany`, шторы `cover.spalnia_uliany_shtora` и колонку `media_player.yandex_station_m00h315204vfpk`
- **THEN** создаётся запись «Спальня Ульяны» с набором сущностей управления, и будильник по умолчанию выключен

#### Scenario: Ничего не выбрано
- **WHEN** пользователь не выбрал ни источников света, ни колонки, ни штор
- **THEN** форма показывает ошибку «Выберите хотя бы одно устройство» и запись не создаётся

#### Scenario: Повтор имени
- **WHEN** пользователь создаёт будильник с именем, которое уже есть у другого будильника
- **THEN** форма показывает ошибку о дублирующемся имени

### Requirement: Изменение состава устройств
Интеграция SHALL давать изменить через options flow все устройства и параметры сценария, кроме имени: тип и содержимое медиа, позицию штор, порог высоты солнца, прерывание при изменении освещения, стартовую громкость. Изменения SHALL применяться без перезапуска HA и без потери текущих значений расписания.

#### Scenario: Замена колонки
- **WHEN** пользователь в настройках будильника меняет колонку на другую
- **THEN** при следующем срабатывании играет новая колонка, а время, дни недели и числовые параметры остаются прежними

### Requirement: Сущности управления будильником
Для каждого будильника интеграция SHALL создать одно устройство со следующими сущностями:
- `switch`: «Включён», «Пропустить следующий», «Шторы только после восхода» (по умолчанию вкл), по одному переключателю на каждый день недели (Пн–Вс);
- `time`: «Время подъёма»;
- `number`:
  - «Длительность рассвета», мин: 1–60, по умолчанию 15;
  - «Включать Станцию за», мин: 0–60, по умолчанию 2;
  - «Максимальная громкость», %: 0–100, по умолчанию 50;
  - «Открывать шторы за», мин: 0–60, по умолчанию 15;
  - «Отложить на», мин: 1–30, по умолчанию 9;
  - «Автостоп через», мин: 0–120, по умолчанию 30, 0 = не останавливать;
- `button`: «Стоп», «Отложить», «Тест»;
- `sensor`: «Следующее срабатывание» (timestamp), «Состояние» (enum).

Все изменения через эти сущности SHALL применяться сразу, в том числе к уже запланированному срабатыванию.

#### Scenario: Изменение длительности рассвета на лету
- **WHEN** будильник стоит на 07:00, сейчас 06:30, и пользователь меняет «Длительность рассвета» с 15 на 25 минут
- **THEN** рассвет начинается в 06:35

#### Scenario: Перенос включения Станции
- **WHEN** будильник стоит на 07:00, и пользователь меняет «Включать Станцию за» с 2 на 10 минут
- **THEN** Станция начинает играть в 06:50, и громкость нарастает до максимальной к 07:00

#### Scenario: Изменение во время идущего рассвета
- **WHEN** рассвет уже идёт и пользователь меняет «Максимальную громкость»
- **THEN** нарастание громкости продолжается до нового максимума

### Requirement: Локализация
Тексты интерфейса (config flow, options flow, названия сущностей, состояния, сервисы) SHALL быть переведены на русский и английский.

#### Scenario: Русский интерфейс
- **WHEN** язык интерфейса HA — русский
- **THEN** форма создания будильника и названия сущностей отображаются по-русски
