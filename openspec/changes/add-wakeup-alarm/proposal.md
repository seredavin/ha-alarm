## Why

В Home Assistant нужны будильники для трёх спален: Спальня, Спальня Александра, Спальня Ульяны. Будильник должен будить «рассветом»: плавно разжигать свет, постепенно поднимать громкость Алисы, открывать шторы, если солнце уже встало. Ни одно готовое решение (блюпринт Sbyx, карточки будильников из HACS, будильники Станции) не умеет всё это сразу и не даёт управлять параметрами из HA. Поэтому делаем свою интеграцию для HACS, которая целиком настраивается через UI.

## What Changes

- Новая кастомная интеграция `wakeup_alarm` («Будильник с рассветом»). Ставится через HACS как custom repository.
- Каждый будильник — отдельная запись интеграции (config entry). Создаётся в UI: имя, источники света (любые `light` и `switch`, например лампы и розетки), колонка, шторы. Интеграция сама определяет, что диммируется, а что нет. Поменять состав устройств можно через options flow.
- У каждого будильника есть сущности для управления из HA и дашборда:
  - включён/выключен, время подъёма, дни недели, «пропустить следующий»;
  - длительность рассвета, максимальная и стартовая громкость, за сколько минут включать Яндекс Станцию и открывать шторы, длительность «отложить», автостоп;
  - кнопки «Стоп», «Отложить», «Тест»;
  - датчики «следующее срабатывание» и «состояние».
- Сценарий пробуждения:
  - за N минут (по умолчанию 15) диммируемые источники плавно разгораются и к времени подъёма доходят до 100%;
  - недиммируемые источники (розетки, обычные лампы) включаются ровно во время подъёма;
  - за M минут (по умолчанию 2, настраивается сущностью в любой момент) Станция начинает играть, громкость линейно растёт до максимальной;
  - за K минут шторы открываются, если солнце над горизонтом.
- Любое изменение освещения не со стороны будильника прерывает его: кто-то включил, выключил или поменял яркость любого из источников, либо остановил Станцию. Считается, что человек проснулся. Поведение отключается опцией.
- Сервисы `wakeup_alarm.stop`, `wakeup_alarm.snooze`, `wakeup_alarm.trigger` и события шины для пользовательских автоматизаций.
- Инфраструктура репозитория: `hacs.json`, README, переводы ru/en, тесты, GitHub Actions (hassfest, HACS validation, pytest).

## Capabilities

### New Capabilities
- `alarm-setup`: создание и редактирование будильника через UI, выбор устройств, установка через HACS.
- `alarm-schedule`: расписание (время, дни недели, разовый будильник, пропуск следующего), расчёт ближайшего срабатывания, сохранение настроек после перезапуска.
- `wakeup-sequence`: сценарий пробуждения: плавный рассвет диммируемых источников, включение недиммируемых, нарастание громкости Станции, открытие штор по солнцу.
- `alarm-control`: управление идущим будильником: стоп, отложить, автостоп, прерывание при изменении освещения, тестовый запуск, сервисы, события, датчик состояния.

## Impact

- Новый репозиторий `seredavin/ha-alarm`, код в `custom_components/wakeup_alarm/`.
- Зависимостей от сторонних библиотек нет. Работает через стандартные сервисы HA: `light`, `switch`, `media_player`, `cover`, `sun`.
- Колонкой управляет через `media_player.play_media` и `media_player.volume_set`. Для yandex_station используется тип контента `command` или `text`.
- Прод: HA 2026.10 в Docker на 192.168.87.135. После установки создаются три записи (по одной на спальню).
